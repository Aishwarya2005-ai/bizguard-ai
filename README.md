# 🛡️ BizGuard AI

BizGuard AI is an AI-powered business risk assessment web application built using Streamlit.

It analyzes business financial data and provides:
- 📊 Risk Score Calculation
- 📈 Risk Probability Analysis
- 🧠 AI Survival Strategy Recommendations
- 💡 Digital Transformation Suggestions
## 🚀 Features
- Clean SaaS-style dashboard
- Intelligent risk scoring system
- Expense-to-revenue analysis
- Visual risk representation
- Actionable business insights
## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
